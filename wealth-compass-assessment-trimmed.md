## Coverage guarantee: how balance is actually achieved

Rather than tuning all 21 questions to be individually balanced, which distorts content, the guarantee runs through 6 anchor questions, 3 per framework, each redesigned to offer exactly one option per category. Everything else is supplementary: it adds texture and differentiates people within a category, but isn't required to be equal, because the anchors already are.

**Navigation preferences** (Structured, Adaptive, Reflective, Collaborative, Intuitive), guaranteed by Q5, Q7, Q8:

|---|---|---|---|---|
| Structured | ✓ | ✓ | ✓ | 3 |
| Adaptive | ✓ | ✓ | ✓ | 3 |
| Reflective | ✓ | ✓ | ✓ | 3 |
| Collaborative | ✓ | ✓ | ✓ | 3 |
| Intuitive | ✓ | ✓ | ✓ | 3 |

Previously Collaborative had a floor of 1 (only Q8). Now equal at 3.
