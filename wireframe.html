Content & design plan — v3 (for review alongside the screens)

Design system · Fintech (Stripe-inspired)

  • Surfaces: bg #F6F9FC, card #FFFFFF, input #F0F3F9
  • Text #0A2540 (high contrast), muted #5A6B85
  • Brand accent: blurple #5851E8 (+ purple #6C63E0 secondary)
  • Type: Sora display · DM Sans body · DM Mono for every $ amount & code
  • Radii 16 / 10 / 20 / pill · 8-pt spacing · ≥44pt touch targets
  • Dark "moment" screens use the system's dark surfaces #0A0E1A → #1C2A4C

Framework 1 · Wealth Compass (WHY) — 8 directions

  • 🛡 Security · 🕊 Freedom · 📈 Growth · ✨ Experiences
  • ❤️ Connection · 🎯 Purpose · 🌳 Legacy · ⚖️ Balance

Shown as the Compass Rose radar (Chart.js) in blurple — the signature visual. Strength read via bar fill/opacity, no per-dimension colours.

Framework 2 · Navigation Preferences (HOW) — 5

📋 Structured · 🌊 Adaptive · 🔍 Reflective · 🤝 Collaborative · 🌿 Intuitive — a blend, shown as bars. Never a "type".

Assessment · 21 questions, 5 sections (trimmed)

  • 1 · Your Money Story (Q1–4)
  • 2 · Navigation Preferences (Q5–8)
  • 3 · Your Wealth Compass (Q9–14)
  • 4 · Money Together (Q15–19)
  • 5 · Shared Future (Q20–21)

Interactions vary: selection cards, sliders, budget allocation, ranking, multi-select, scenarios. Weighted scoring — balance guaranteed by 6 anchor questions (3 per framework, one option per category): Compass via Q10/Q17/Q20, Navigation via Q5/Q7/Q8.

Sharing & storage

  • Netlify hosts the app; Firebase (Firestore) stores shared profiles (client-side SDK, no server code)
  • Handoff: cloud share code + link (primary), encrypted file fallback
  • Passphrase-encrypted on-device before upload — Firestore holds only ciphertext
  • Trade-off: one-time Firebase setup + security rules (no longer zero-config)

Reports & tone

  • Three PDFs: My Wealth Compass, My Navigation Preferences, Our Shared Compass (overlaid roses; Shared Direction / Complementary Perspectives / Different Areas of Focus / Opportunities for Alignment / 90-day plan)
  • Avoid: personality, strength, weakness, right, wrong, good, bad, must, should — and spender/saver/risk-taker labels
  • Use: "your compass naturally points towards…", "you tend to prioritise…", "you may wish to explore…", "together you can…"
  • Calm, curious, encouraging, premium — grounded copy, no purple prose. Recurring question: "What kind of financial future are we building together?"
